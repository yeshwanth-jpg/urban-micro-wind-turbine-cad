# Urban Micro Wind Turbine CAD Design & Simulation

## 📌 Project Overview
A comprehensive design and performance analysis study of a compact, low-start-up Vertical-Axis Wind Turbine (VAWT) optimized for highly turbulent, lower-velocity urban wind environments.

![CAD Render Preview](Contra-Rotating%20Wind%20Turbine%20CAD...)

## ⚙️ Key Design Features
*   **Low-Start-Up Torque:** Design optimized for an extremely low self-starting threshold, crucial for intermittent urban winds.
*   **Modular 3-Blade Geometry:** Features a high-fidelity CAD model assembly with integrated lightning protection and modular interlocking blade sections for manufacturing.
*   **Integrated Generator Hub:** Includes a detailed design for a bottom-mounted direct-drive permanent magnet generator hub.

## 🛠️ Tech Stack
*   **3D CAD Modeling:** SolidWorks (parametric modeling, assembly design)
*   **Simulation & Analysis:** ANSYS Workbench (CFD for blade aerodynamics, Static Structural FEA)
*   **Simulation Core:** Python (System performance modeling, generator load calculations)
